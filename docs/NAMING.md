# Ürün adı adayları

Karar Doğu'nun. Bu dosya karar verilince silinir ve sonuç `DECISIONS.md`'ye yazılır.

Kural: Age of Empires veya başka bir oyunun adını, terimlerini çağrıştıran ad kullanılmaz.

| Aday             | Anlamı                          | GitHub kullanıcı/org adı      | Benzer ürün | Not                                                                                                |
| ---------------- | ------------------------------- | ----------------------------- | ----------- | -------------------------------------------------------------------------------------------------- |
| **Hisar**        | Türkçe "kale"; çalışma adı      | Dolu (`github.com/hisar` var) | Bulunamadı  | Repo `lazypanic999/hisar` olarak zaten açık. Kısa ve özgün ama İngilizce konuşanlar için anlamsız. |
| **Commitadel**   | commit + citadel (kale)         | Boş                           | Bulunamadı  | Ne yaptığını tek kelimede anlatıyor; yazımı biraz zor.                                             |
| **Gitstead**     | git + homestead (yurt, çiftlik) | Boş                           | Bulunamadı  | Kişisel üs fikrine uygun, söylemesi kolay.                                                         |
| **Repohold**     | repo + stronghold               | Boş                           | Bulunamadı  | Okunuşu net, anlamı açık.                                                                          |
| **Gitchronicle** | git + chronicle (vakayiname)    | Boş                           | Bulunamadı  | Zaman tüneli vurgusu en güçlü aday; uzun.                                                          |

**Kontrol edilenler (2026-11-17):** GitHub kullanıcı/org adı (`github.com/<ad>` 404 dönüyorsa boş) ve web aramasında aynı adlı ürün.

**Kontrol edilemeyenler:** npm paket adı ve alan adı. Bu oturumdan npm kayıt deposuna ve alan adı sorgularına erişilemedi. Karar öncesi elle bakılacak:

- `https://www.npmjs.com/package/<ad>`
- Alan adı: `<ad>.dev`, `<ad>.app`, `<ad>.io` (öğrenci paketindeki ücretsiz alan adı seçenekleri dahil)

**Önerim:** Zaman tüneli ürünün tek farkı olduğu için **Gitchronicle**, kısalık önemliyse **Gitstead**.
